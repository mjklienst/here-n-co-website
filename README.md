# here, & co. static website

A lightweight multi-page static website for here, & co. in Yamhill, Oregon.

## Files

- `index.html` - landing page
- `about.html` - about page
- `menu.html` - menu page
- `gather.html` - gatherings/seasonal page
- `visit.html` - address/contact page
- `css/styles.css` - shared styles
- `js/main.js` - mobile menu and footer year
- `images/` - logo/interior images

## Run locally

Open `index.html` in your browser, or use VS Code with the Live Server extension.
